---

## 行为定稿

| 项 | 定稿 |
|----|------|
| 快捷键 | **⌘⇧A** 切换助手侧栏 |
| 「登录助手…」「站点备忘…」 | **打开侧栏**并切到对应类型过滤；底栏「高级设置…」进原设置窗 |
| 与通知侧栏 | **互斥** |
| SB-2 Recipe 编辑 | 选中登录行 → 下半区详情；「＋登录」新建；点选；Keychain 存凭证 |
