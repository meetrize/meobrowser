# 自动滚动速度精细化 — 设计方案

> 状态：**已完成（AS-0～AS-2）**  
> 范围：设置「自动滚动速度」滑杆范围与慢速仍可滚的引擎行为  
> 相关：`chrome-more-menu-design.md`（自动滚动主设计）

---

## 1. 背景与问题

| 现象 | 原因（当前实现） |
|------|------------------|
| 滑杆最大 **500 px/s** 偏猛 | `BrowserAutoScrollPreferences` / 设置滑杆 `maxValue = 500` |
| 约 **≤25 px/s** 几乎不滚 | `tick` 约 30Hz；`delta = speed × dt`，若 `delta < 0.5` **直接 return**；10 px/s 时每帧约 **0.33px**，永远达不到阈值 |
| 即使去掉阈值，慢速仍可能「抖停」 | 部分页面 `scrollTop` 按整像素落地；亚像素步进被吞掉 |

用户目标：

1. **上限改为 200 px/s**  
2. **下限精细到约 10 px/s**，仍能持续、很慢地滚  

---

## 2. 产品定稿（建议）

| 项 | 定稿 |
|----|------|
| 单位 | 仍为 **px/s**（与现文案一致） |
| 范围 | **10～200**（含端点） |
| 默认 | **80**（仍在新范围内；已存偏好若 >200 则钳到 200，若 <10 则钳到 10） |
| 滑杆 | 连续；旁标显示整数，如 `10 px/s` … `200 px/s` |
| 慢速语义 | 10 px/s = 约每秒下移 10 像素；观感为匀速细挪，不要求每帧都动 1px |
| 即时生效 | 保持：滚动中改滑杆立即变速 |
| 与其它打断 | 不变：到底停、滚轮取消勾选、指针入窗暂停/出窗继续 |

### 2.1 不做（本轮）

- 非线性滑杆（对数档）——范围收窄到 200 后线性足够  
- 按「行/屏」速度单位  
- 横向滚动  

---

## 3. 技术定稿：亚像素累积（核心）

### 3.1 问题本质

慢速时单帧位移常 **&lt; 1px**。不能「不足 0.5 就丢弃」，否则低速永远不滚。

### 3.2 方案：carry 累积

控制器增加浮点累加器 `pendingScrollPx`（每窗一份）：

```text
每 tick（未 pause、enabled）：
  pending += speed * dt
  if pending < 1.0: return          // 攒够至少 1 整像素再写 scrollTop
  step = floor(pending)             // 或 trunc toward +∞ for 向下滚
  pending -= step
  evaluateJS: scrollTop += step
```

| 速度 | 约多久动 1px（30Hz） |
|------|----------------------|
| 10 px/s | ~0.1 s 动一次 1px |
| 20 px/s | ~0.05 s |
| 80 px/s | 多数帧 ≥1px，流畅 |
| 200 px/s | 每帧约 6～7px |

### 3.3 为何不用「去掉 0.5 阈值、直接加小数」

- 部分站点/`scrollingElement` 对小数 `scrollTop` 行为不一致（取整、忽略）。  
- **整像素步进 + 时间累积** 更稳，慢速表现为低频 1px 点动，符合「很慢」预期。

### 3.4 启停与暂停时清不清 carry

| 事件 | 处理 |
|------|------|
| 开启自动滚 / 指针移出恢复 | `pending = 0`，重置 `lastTickTime`（避免大跳） |
| 指针入窗暂停 | **保留** pending（或清零均可；建议 **清零**，恢复更干净） |
| 关闭 / 滚轮打断 / 到底 | `pending = 0` |

### 3.5 到底判定

仍用现有 `atBottom` JS 结果；与步进大小无关。注意：慢速到底时最后几像素用 `step` 正常推进即可。

## 4. 偏好与设置 UI

| 文件 / 点 | 变更 |
|-----------|------|
| `BrowserAutoScrollPreferences` | `kMinSpeed=10`，`kMaxSpeed=200`；`clamp` 读写统一 |
| `BrowserSettingsWindowController` | 滑杆 `minValue=10`，`maxValue=200`；文案可略改：「约 10～200 像素/秒」 |
| 设计文档中旧范围 20～500 | 同步改为 10～200 |

迁移：无单独 version key；读旧值经 `clamp` 自然落入新区间。

## 5. 验收标准

- [x] 设置滑杆范围 **10～200**，默认显示与偏好一致（默认 80）  
- [x] **10 px/s** 长页可持续向下滚（很慢，允许一顿一顿 1px）  
- [x] **200 px/s** 明显快于默认，但不至于失控飞页  
- [x] 滚动中拖滑杆速度即时变  
- [x] 指针入窗暂停 / 出窗继续；滚轮仍取消勾选  
- [x] `make browser` 通过
